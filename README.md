# Library Management System (Java)

A console-based Library Management System developed using Core Java. This project allows users to manage books, track issued books, and maintain library records using file handling.

## Features

- Add new books
- View all books
- Search books
- Issue books to students
- Return books
- Delete books
- View issued books with student names
- Check book availability
- Library statistics (total, available, and issued books)
- Save and load records using file handling

## Technologies Used

- Java
- ArrayList
- Scanner
- File Handling
- PrintWriter

## How to Run

1. Clone this repository.
2. Open the project folder in terminal.
3. Compile the Java file:

   `javac LibraryManagement.java`

4. Run the application:

   `java LibraryManagement`

## Data Storage

The application stores book records in `libraryData.txt` so data can be loaded again when the program starts.

## Project Structure

- `LibraryManagement.java` — Main application source code
- `libraryData.txt` — Local data file (created automatically when the application saves data)
